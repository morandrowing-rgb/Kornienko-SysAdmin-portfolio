# Портфолио системного администратора

Александр — системный администратор / инженер инфраструктуры.
Опыт: поддержка пользователей и рабочих мест, Linux и Windows Server,
Active Directory, локальные сети, резервное копирование, автоматизация рутины на Bash/Python.

Это **учебные и практические проекты**: каждый — небольшой, но реально запускаемый.
Скрипты проверялись в Linux-окружении (`bash -n`, тестовый запуск на временных данных).

| № | Проект | Что делает | Стек |
|---|--------|-----------|------|
| 1 | [Резервное копирование](./01-backup-bash) | tar-архив + инкрементная копия rsync, контрольная сумма, ротация старых копий, лог, cron | Bash, tar, rsync, cron |
| 2 | [Отчёт о состоянии сервера](./02-health-report) | Диски, память, нагрузка, службы, порты → текстовый и JSON-отчёт | Python 3 (stdlib) |
| 3 | [Стенд AD / LDAP](./03-ad-ldap-stand) | Описание поднятия стенда, запросы к AD из PowerShell и к LDAP из Linux, пример smb.conf | PowerShell, ldapsearch, Samba |
| 4 | [Мониторинг доступности сервисов](./04-service-monitoring) | Проверка TCP/HTTP по списку узлов, лог, код возврата для cron/алертов | Bash, curl |

Контакты — в резюме на HeadHunter и в сопроводительных письмах (в репозитории личные контакты не публикую).
