# 03 — Стенд Active Directory / LDAP

Цель стенда: безопасно отрабатывать типовые задачи сисадмина — поиск учёток,
отключённые/заблокированные пользователи, состав групп, инвентаризация ПК —
не трогая боевой домен.

## Как поднимал стенд (кратко)
1. Windows Server (VM) → установка роли AD DS → повышение до контроллера домена `example.local`.
2. OU `Users/Computers/Groups`, тестовые пользователи и группы, GPO на парольную политику.
3. Вторая VM (Linux) — ввод в домен / проверка LDAP-запросами из `ldap_search_examples.sh`.
4. Опционально Samba-файловый ресурс (`smb.conf.example`, проверка — `testparm`).

## Файлы
- `ad_queries.ps1` — готовые one-liner'ы PowerShell (закомментированы: копировать по одному).
- `ldap_search_examples.sh` — те же вопросы из Linux; без `RUN=1` только печатает команды.
- `smb.conf.example` — пример шары.

Домены, имена и адреса здесь вымышленные (`example.local`) — боевых данных в репозитории нет.
