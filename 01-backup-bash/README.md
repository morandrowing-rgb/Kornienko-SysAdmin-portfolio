# 01 — Резервное копирование (Bash, tar + rsync, cron)

Что делает `backup.sh`:
1. Создаёт датированный `tar.gz`-архив указанных каталогов и его `.sha256`.
2. Если есть `rsync` — обновляет зеркало `mirror/` (быстрый доступ без распаковки).
3. Удаляет архивы старше `RETENTION_DAYS` (ротация).
4. Пишет лог в `DEST_DIR/backup.log`. Режим `--dry-run` только показывает команды.

## Запуск
```bash
cp backup.conf.example backup.conf   # поправить пути
./backup.sh --dry-run backup.conf    # проверка без изменений
./backup.sh backup.conf              # боевой запуск
sha256sum -c backup-*.tar.gz.sha256  # проверка целостности
```
По расписанию — см. `crontab.example` (`crontab -e`).

## Проверка на тестовых данных (как проверялось)
Созданы временные каталоги с файлами → запуск в тестовый `DEST_DIR` →
архив и контрольная сумма на месте, `sha256sum -c` = OK, повторный запуск
создаёт второй архив, ротация не трогает свежие файлы.
